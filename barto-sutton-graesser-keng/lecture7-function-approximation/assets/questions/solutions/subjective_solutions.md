# Solutions to Subjective Questions (Chapter 9)

1. **The Core Trade-off:** In tabular methods, we can achieve perfect accuracy for every state (asymptotically) because each state has its own independent parameter. However, learning is extremely slow because visiting one state teaches us nothing about others. Function approximation sacrifices perfect accuracy (we can no longer perfectly represent the value of *every* state due to fewer parameters than states) in exchange for generalization and vastly faster learning, as an update to one state improves the estimates of all similar states.
2. **Semi-gradient vs True Gradient:** True SGD updates weights based on the gradient of the error: $\nabla [U_t - \hat{v}(S_t, \mathbf{w})]^2$. If the target $U_t$ is the TD target $R_{t+1} + \gamma \hat{v}(S_{t+1}, \mathbf{w})$, then the target *depends* on $\mathbf{w}$. True SGD would require computing the gradient of the target as well. Semi-gradient methods ignore this and treat the target as a constant $c$, only computing the gradient of the prediction $\hat{v}(S_t, \mathbf{w})$. They lose robust mathematical convergence guarantees (except in the linear case), but we use them because they are much faster, can be used online, and allow for bootstrapping (learning before the episode ends).
3. **Value Error ($\overline{VE}$):** We weight by $\mu(s)$ because in function approximation, we cannot get the value of every state perfectly right. If we have to accept errors, we want those errors to occur in states we rarely or never visit. If we used uniform weighting in an infinite space, the optimization would waste its limited parameter capacity trying to perfectly fit the values of states the agent will never encounter, severely degrading performance in the states the agent actually visits.
4. **Coarse Coding Intuition:** Larger receptive fields mean that a single state activates features that cover a much wider area of the state space. Therefore, an update in one state will generalize to a much broader region. This results in faster initial learning but reduces the ability to learn fine-grained, sharp distinctions between nearby states (loss of resolution).
