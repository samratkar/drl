# Solutions to Subjective Questions (Lecture 8)

1. **The Curse of Dimensionality:** Atari states are raw RGB pixels. Even downsampled to 84x84, the number of possible states is astronomically large ($256^{84\times84\times1}$ for grayscale). A tabular method requires a distinct memory slot for every possible state, which is computationally impossible and prevents generalization. Function approximation solves this by learning a compressed representation (weights) that maps similar pixel inputs to similar Q-values, generalizing across states without memorizing them.
2. **Experience Replay Limitations:** Experience Replay stores transitions $(s, a, r, s')$ generated by older, historical policies. To learn from these transitions, the algorithm must be off-policy (able to learn the optimal policy while learning from data generated by a different behavior policy). Standard SARSA is strictly on-policy; it requires the next action $A_{t+1}$ to be generated by the *current* policy to calculate the TD target. Therefore, SARSA cannot use Experience Replay. Q-learning is off-policy (it takes the max over all actions for the target, regardless of what the old policy actually did), making it perfectly suited for Experience Replay.
3. **The Mathematics of Bias:** Let $X_1, X_2, \dots$ be unbiased but noisy estimates of true values $v_1, v_2, \dots$. Even though the expected value of each estimate is correct ($E[X_i] = v_i$), the $\max$ operator will "cherry-pick" the noise. If $X_1$ accidentally has a large positive error, it becomes the maximum, pulling the entire result upward. Thus, $E[\max(X_i)] \ge \max(E[X_i])$. This leads to a systematic positive bias.
