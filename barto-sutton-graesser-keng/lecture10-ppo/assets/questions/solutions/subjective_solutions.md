# Solutions to Subjective Questions (Lecture 10)

1. **Sample Efficiency:** REINFORCE is strictly on-policy. The moment you perform one gradient update, the policy changes ($\pi_{new} \neq \pi_{old}$). The math of REINFORCE requires the data to be generated by the *current* policy, so all the data you just gathered must be thrown away after one single step. PPO is sample efficient because the Probability Ratio $r_t$ actively corrects for the difference between $\pi_{old}$ (the data gatherer) and $\pi_{new}$ (the current network). This allows PPO to run multiple epochs (e.g., 4 or 10 passes) of SGD over the *same batch of data* before throwing it away.
2. **The Minimum Operator:** The $\min()$ operator acts as a pessimistic bound. We only clip the objective if the update makes the objective *better*. For example, if $A_t > 0$ and $r_t = 1.5$ (action was good, and we heavily increased its probability), we clip it to $1.2$ so we don't over-update. BUT, what if $A_t > 0$ and $r_t = 0.5$ (the action was good, but our neural network accidentally *decreased* its probability)? We WANT the network to fix this mistake! The unclipped value ($0.5 \times A_t$) is *lower* than the clipped value ($0.8 \times A_t$). The $\min()$ operator selects the unclipped value, keeping the gradient alive so the network can aggressively correct its mistake and pull $r_t$ back up toward $1.0$.
